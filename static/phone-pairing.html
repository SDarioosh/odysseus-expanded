Pair a phone

Sets up the Athena relay app on a phone in one step: it then uploads the watch's recordings and syncs the T5 through Odysseus.

  • In the relay app: Settings → Pair with Odysseus, then scan this code.
  • The code works once and for 10 minutes. It doesn't contain a password: the phone trades it for its own API token, named "Phone relay" with the date.
  • Each phone's token is listed in Settings → API tokens; revoke it there to unpair that phone.
