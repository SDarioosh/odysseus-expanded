# QC of handwritten notes H2 (PR 92), 2026-10-26

An external bug hunt checked PR 92 ("feat(ink): handwritten notes H2, transcribe pages
and review the text", head `20237f8`), findings O-1 to O-9 and the cross-PR finding X-1.
Each finding was first written as a test and run on the unchanged code; a test that
failed there counts as reproduced. Plan and behaviour: [handwritten-notes.md](handwritten-notes.md).

Verdicts: **C** confirmed and fixed, **P** partly confirmed, **N** not reproduced,
**D** needs an owner decision (not changed).

| Finding | Verdict | What was wrong | Fix | Test |
|---|---|---|---|---|
| O-1 stroke in the margin crashes `page_bands` | C | The hub accepts points 50 units outside the page. A stroke wholly below (or above) the paper gave a band with top > bottom, and PIL's crop raised `ValueError`. The run caught it, so the page went `failed` with that error rather than the hub crashing. | `_extents` cuts stroke spans to the paper and leaves out ink wholly off it, as the render does. | `test_qc_o1_strokes_in_the_margin_below_or_above_the_page` |
| O-2 `content` loses reviewed text of a page read again | C | `note_content` took only `reviewed` pages. After a reviewed page was read again (its text in `previous`), Save review on another page dropped it from `content`, which the plan says must not happen. | A page that isn't `reviewed` contributes its `previous` text. | `test_qc_o2_content_keeps_reviewed_text_of_a_page_read_again` |
| O-3 forced cuts overlap 108 units, one line deduplicated | C | A forced cut had `OVERLAP` on each side plus `PAD` of paper on each side: 108 units, about 2.5 ruled lines. `join_bands` dropped only one repeated line, so two lines in the overlap were written twice. | No paper at a forced cut (overlap 60 units), and `join_bands` drops the longest repeated run of up to 3 lines at an overlap seam. | `test_qc_o3_forced_cuts_overlap_by_overlap_and_the_seam_is_kept_once` |
| O-4 strokes drawn while a page is read are never read | C | `_prepare` skipped every `pending` page. A leave during a run asked for nothing, the view forgot the page, and the old run stored text for the old strokes. | A run stores the hash of the strokes it reads (`transcript.reading`). A pending page whose strokes no longer match needs transcribing, and a new run takes it over. The existing job check drops the older run's result. | `test_qc_o4_strokes_added_while_a_page_is_read_are_read_after` |
| O-5 older GET overwrites the transcribe answer and stops polling | C | The Text tab sends the transcribe POST and the transcripts GET together. When a GET answered before the POST arrived after it, the tab showed "Not transcribed yet" and never polled. Reproduced in Chromium. The 404 "not on the hub yet" message for a brand-new note only lasts until the POST answer arrives. | Transcript questions are numbered, and an answer older than the one shown is dropped. A dropped poll answer still schedules the next poll. | browser check `qc_o5_old_transcripts_answer_is_dropped` |
| O-6 braces in the words around the JSON | C | `parse_answer` sliced from the first `{` to the last `}`. | It decodes from each `{` in turn (`raw_decode`) and takes the first object with a string `text`, so the outer object still wins over text that quotes JSON. | `test_qc_o6_parse_answer_with_braces_in_the_words_around_it` |
| O-7 blank page stays in Needs review | C | On a page without ink, `needs_transcription` also required non-empty text. A page read as `""` and then erased stayed `machine`. | Any page with status other than `none` whose strokes changed is cleared once. | `test_qc_o7_a_page_with_empty_machine_text_is_cleared_when_its_ink_is_erased` |
| O-8.1 a draft equal to the hub's text hides new transcriptions | C | A draft typed back to the hub's text was kept, so it hid the next transcription and showed "Edits not saved yet". | A draft equal to the hub's text is dropped, in memory and in IndexedDB. | browser check `qc_o8_no_op_draft_is_dropped` |
| O-8.2 Restore + Save on a changed page marks new strokes reviewed | D | Confirmed in the code: Save review stamps the current strokes' hash on whatever text is saved, including restored text. This is how review is specified ("reviewed for the page's strokes as they are now"). The Text tab draws the current strokes and warns in red that the writing changed. | None. Owner: should Save review on a changed page ask first, or keep the page marked changed? | — |
| O-8.3 the list loses review badges of unsynced notes | C | A note with unsynced edits was rebuilt from the device copy without the hub's `transcripts` summary. | The summary is kept. | browser check `qc_o8_list_keeps_review_of_unsynced_note` |
| O-8.4 closing Write doesn't read changed pages | C | `suspend()` saved but never called `autoTranscribe`, unlike Back, opening another note and hiding the app. | `suspend()` calls it. | browser check `qc_o8_closing_write_reads_changed_pages` |
| O-8.5 deleting a note leaks its drafts | C | Drafts stayed in IndexedDB after a delete here, a 410, a 404 on refresh, or the list sweep. | They are dropped with the note in all four paths. | browser check `qc_o8_delete_drops_drafts` |
| O-9.1 `cut_bands` loops forever for a small `max_band` | C | Confirmed, and the bound is `max_band <= 2 * OVERLAP` (60), not 40. Only the `MAX_BAND` default (560) is used today. | `cut_bands` raises `ValueError` for such a value. | `test_qc_o9_cut_bands_refuses_a_band_too_small_to_make_progress` |
| O-9.2 Text tab image not redrawn on rotation | C | The resize observer watched only the Write canvas, which is hidden in the Text tab. | It also watches the Text panel, and a new size or `orientationchange` redraws the page image. | browser check `qc_o9_text_image_follows_resize` |
| X-1 H2 limits exceed Athena's `/ingest/text` | D | Correct comparison: H2 allows 60 × 20,000 characters and lines of any length, while H3 allows 200,000 characters, 5,000 lines and 4,000 characters per line, and refuses text without words. Nothing is sent in H2, so nothing fails today. | No H2 code change. The limits are written down for H4 in [handwritten-notes.md](handwritten-notes.md#5-into-athena): check before sending and tell the owner. Athena now wraps a line over 4,000 characters at a space instead of refusing it (SDarioosh/Athena#110). | — |
